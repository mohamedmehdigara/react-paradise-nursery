# Paradise Nursery - Online Plant Shop

Paradise Nursery is a modern React and Redux Toolkit web application designed for houseplant enthusiasts. Users can explore curated plant categories, learn about plant care, add items to a dynamic shopping cart, and manage their orders seamlessly.

## Features
- **Landing Page**: Immersive welcome page with background visuals and company introduction.
- **Product Catalog**: 18+ unique houseplants grouped into 3 distinct categories (Air Purifying, Aromatic, and Low Maintenance).
- **Dynamic Shopping Cart**: Real-time cart badge counter, quantity adjustments, item removal, and subtotal calculation managed via Redux Toolkit.
- **Responsive Layout**: Clean navigation header and accessible UI components.

## Tech Stack
- **Frontend**: React.js (Vite/CRA)
- **State Management**: Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- **Styling**: Standard CSS3 with CSS Grid & Flexbox
